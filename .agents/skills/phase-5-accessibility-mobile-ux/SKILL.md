# Phase 5C Accessibility + Mobile UX Gate

RAMS should treat `accessibility-audit` findings as part of the Mobile UX pipeline evidence bundle.

## Rules

- Accept WCAG 2.2 AA / WCAG 2.1 AA mapped findings from `accessibility-appendix.json` and `report.json`.
- Map missing accessible names, labels, alt text, link purpose and heading-order defects to governed website source files.
- Keep remediation PR-gated. Do not auto-merge accessibility changes.
